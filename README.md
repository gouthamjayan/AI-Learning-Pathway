# AI Pathway

Welcome to **AI Pathway** — a personal repository documenting my learning journey across Machine Learning and Deep Learning. Everything here is built to understand how models work under the hood rather than treating them as black boxes, and it can also serve as a practical reference for anyone diving into AI fundamentals.

## What's Inside

This repository is organized into two main tracks[cite: 1]:

### Machine Learning
- **[Linear Regression](./Machine_Learning/Linear_Regression/README.md)** — Fitting linear relationships to predict continuous values (includes NumPy and standard implementations)[cite: 1].
- **[Logistic Regression](./Machine_Learning/Logistic_Regression/README.md)** — Modeling probabilities and classification boundaries using linear scores and activation functions[cite: 1].
- **[Decision Tree](./Machine_Learning/Decision_Tree_Regression/README.md)** — Splitting feature space using threshold rules *(update folder name/link to match your exact directory)*[cite: 1].

### Deep Learning
- **[MLP (Multi-Layer Perceptron)](./Deep_Learning/MLP/README.md)** — Dense layers, activations, and learning mechanics across Python and C++ implementations[cite: 1].
- **[CNN (Convolutional Neural Network)](./Deep_Learning/CNN/README.md)** — Spatial feature extraction using filters/kernels[cite: 1].
- **[Transformers](./Deep_Learning/Transformer_.../README.md)** — Token & positional embeddings, transformer blocks, normalization, vocabulary projections (`logits`), and softmax/probabilities *(update folder name/link to match your exact directory)*[cite: 1].

## How to Use This Repo as a Reference

1. **Start with the fundamentals:** Look through `Machine_Learning` first to build intuition around loss, optimization, decision boundaries, and feature representations[cite: 1].
2. **Move to neural networks & sequence models:** Explore `Deep_Learning` to see how hidden representations, projections, and probability distributions work in practice[cite: 1].
3. **Read the notes alongside the code:** Each topic folder has its own `README.md` with key concepts and takeaways paired with the implementation files[cite: 1].
